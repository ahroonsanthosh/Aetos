# Bundled typefaces

Both faces are vendored rather than linked from a font CDN. A console for a defence site should
not make a third-party request on load, and it has to render correctly with no outbound network
at all.

| File | Family | Licence |
|---|---|---|
| `space-grotesk-latin.woff2` | Space Grotesk (variable, 300–700), by Florian Karsten | SIL Open Font License 1.1 |
| `ibm-plex-mono-{300,400,500}.woff2` | IBM Plex Mono, by Mike Abbink / Bold Monday for IBM | SIL Open Font License 1.1 |

Latin subsets only. The full OFL text is at <https://openfontlicense.org>.
