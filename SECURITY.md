# Security

Aetos is an operator console for counter-drone work. It holds accounts, sessions and an audit
trail, and it serves a live picture of a site, so a hole in it matters.

If you find a way to get past the login, read or change data you shouldn't, run code on the
server, or make it lie about what its sensors are seeing, please tell me privately. Use
**Report a vulnerability** on this repo's Security tab. Please don't open a public issue for it.

It's just me maintaining this, so give me a few days to reply.

In scope: the code in this repo (the backend, the sensor adapters, the operator console and the
digital twin). What already defends what is written up in
[docs/deployment.md](docs/deployment.md); a report that breaks one of those claims is exactly
what I want to hear about.
